# CMS Assignment

This project is built using Umbraco CMS and deployed on an Azure WebApp. 
The goal was to design and structure web pages based on a provided Figma design file. 
The application uses a dynamic content structure with both Block Grid and Element Types, allowing content creators to easily build and modify pages.

The project includes functional forms with Surface Controllers, dynamic navigation, and responsive design for mobile, tablet, and desktop views.
Email confirmation is implemented for form submissions. All pages are published and accessible via Azure WebApp, and the project meets the criteria for an advanced grade.
